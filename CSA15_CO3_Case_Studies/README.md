This folder contains three runnable browser prototypes prepared from the supplied case-study question paper:
1. Smart Retail Inventory Management System
2. Cloud-Based Document Collaboration System
3. Online Food Ordering Platform

Open `case1.html`, `case2.html`, or `case3.html` in a browser to run the prototypes.

The `screenshots/` folder contains output captures from the prototype implementations. These are local prototype outputs, not screenshots from a live paid cloud account.
